# F3 BOM 页签验收要点（v1，2026-10-14）
联调数据：8011 种子 FED-FG（v1 已取代、v2 生效、v3 作废、v4 草稿），单位换算 KG→G、BOX→EA、L→ML。

1. 位置：BOM 页签只出现在产品详情；物料详情没有。
2. 版本列表：四种状态都显示，状态中英文正确；时间按 UTC 解析后以本地时区显示。
3. 新建：生成草稿；明细可选单位，可选范围来自单位换算；数量按后端 Decimal(18,6) 回显，不在前端四舍五入。
4. 编辑：只有草稿可编辑；生效、作废、已取代的版本是只读，编辑按钮置灰并带悬停原因（FE-02）。
5. 生效：v4 生效后 v2 变为已取代；请求体是空的或 {}，不带任何字段（D32，带字段会返回 422）。
6. 作废、复制：同上，请求体为空；复制得到新的草稿版本，明细与源版本一致。
7. 错误：422 按路径定位到字段，路径从 0 开始（D38）；409 等冲突有中英文提示；不展示原始英文报错。
8. 权限：没有 BOM 写权限的用户，新建、编辑、生效、作废、复制都置灰；后端 403 时只提示无权限，不暴露字段细节（D34）。
9. 不在范围内：用量比对（属于 F4）、单位换算维护页（属于 F8）。
10. i18n：中英文切换无漏翻，菜单和页签名称都要检查。

## v1.1 补充（2026-10-14）
11. 组件可选半成品（component_type=product）；页签两级树展示，半成品节点只读展开其当前生效版本（bom.md §7.1）。
12. 草稿中可编辑替代料：增删替代物料、设置优先级；权限 mes.bom:write（§7.2）。
13. 草稿明细保存为一次整单提交（后端事务），失败时整单不生效，页面保留用户输入。
